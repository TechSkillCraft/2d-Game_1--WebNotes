# ✅ **Git Commands (from add → commit → push)**

### **1️⃣ Check current status**

```bash
git status
```

### **2️⃣ Add all new/updated files**

```bash
git add .
```

### **3️⃣ Commit the changes with a message**

```bash
git commit -m "Your commit message"
```

### **4️⃣ Push to GitHub**

```bash
git push origin main
```

> ⚠️ If your branch is **master**, then use:

```bash
git push origin master
```

---

# 🔰 **If pushing for the first time (when repo is new):**

### **Connect your local folder to GitHub repo**

```bash
git remote add origin https://github.com/your-username/react_game1.git
```

### **Set default branch**

```bash
git branch -M main
```

### **Push**

```bash
git push -u origin main
```
