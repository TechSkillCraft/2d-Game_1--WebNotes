# Stage 1 - 🎮 Explore the World of 2D Gaming with Java!

Dive into an exciting 2D game built entirely with Java. This game combines smooth animations, interactive gameplay, and fun challenges to keep you engaged. Whether it’s dodging obstacles, collecting rewards, or exploring dynamic levels, every element is crafted to bring an immersive experience to your screen. Perfect for game enthusiasts and Java learners alike, this project showcases how creativity meets coding in the world of game development.

**Features:**

- Smooth 2D graphics and animations
- Interactive gameplay with user-friendly controls
- Multiple levels and challenges
- Built using Java Swing and AWT

Discover the fun and see how Java brings 2D games to life!
